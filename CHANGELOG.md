# Changelog

## 0.1.0

- Four Google ADK agents (triage, enrichment, investigator, reporter), each served over A2A with its own Agent Card,
  orchestrated by deterministic code via `RemoteA2aAgent`.
- Data from the read-only mcp-wazuh MCP server over stdio, with a per-agent tool allowlist enforced in code.
- Pydantic contracts between agents; `injection_suspected` lifted from mcp-wazuh by a callback and propagated;
  severity floored at the Wazuh rule level; suggested actions generated by code, always `requires_human_approval`.
- Reports are made inert: images, raw HTML and link definitions removed, URLs defanged.
- Limits: steps, timeout, LLM calls, tool calls, token budget. JSONL audit with a correlation id.
- Model via env (Gemini, or any LiteLLM model such as OpenRouter); `MODEL_EXTRA_BODY` for router plugins.
- Validated against a live Wazuh 4.14 lab with Gemini 2.5 Flash and the Jev router.
